# DeepMLBot — Face Detection Telegram Bot

Этот проект представляет собой Telegram-бота для демонстрации работы модели **детекции лиц**. Бот создан в рамках лабораторной работы, чтобы наглядно показать, как современные модели машинного обучения могут быть интегрированы в простые и полезные приложения. Просто отправьте фото, и бот найдет на нем все лица

## Возможности

*   **Обнаружение лиц** на фотографиях, отправленных боту.
*   **Отрисовка bounding boxes** (прямоугольников) вокруг каждого найденного лица.
*   Возврат обработанного изображения пользователю.

## Технологии

*   **Язык:** Python 3.8+
*   **Основные библиотеки:**
    *   `python-telegram-bot` (или `aiogram`) – для взаимодействия с Telegram API.
    *   `OpenCV` (`opencv-python`) – для обработки изображений и отрисовки рамок.
    *   `torch` / `tensorflow` – в зависимости от используемой модели.
*   **Модель детекции:** YoloV8(n)

## Установка и запуск

Чтобы запустить бота локально, выполните следующие шаги:

1.  **Клонируйте репозиторий:**
    ```bash
    git clone https://github.com/obezyan21/deepmlbot.git
    cd deepmlbot
    ```

2.  **Установите зависимости:**
    Рекомендуется использовать виртуальное окружение.
    ```bash
    pip install -r requirements.txt
    ```

3.  **Настройте переменные окружения:**
    Создайте файл `.env` в корне проекта и добавьте токен вашего бота:
    ```
    BOT_TOKEN=ваш_супер_секретный_токен_от_BotFather
    ```
    *(Либо вы можете указать токен прямо в `main.py`, но через `.env` безопаснее)*

4.  **Запустите бота:**
    ```bash
    python main.py
    ```

## Как это работает?

1.  Пользователь отправляет боту фотографию.
2.  Бот принимает изображение и передает его в функцию детекции.
3.  Загруженная модель машинного обучения анализирует снимок и возвращает координаты всех обнаруженных лиц.
4.  С помощью OpenCV на исходном изображении рисуются зеленые прямоугольники.
5.  Финальное изображение отправляется пользователю обратно в чат.
